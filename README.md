# π秒見積もり

稲刈り遠征中に思いついたクソゲー。

- 必要人数：2人以上推奨、1人でも可
- 遊び方：ボタンを押してスタート → π秒（3.14159…秒）経ったと思ったらもう一度押す。小数点以下何桁までπと一致したかを競う。同じ桁数ならπとの差が小さい方が勝ち。

## 遊べるモード

- **この端末で遊ぶ**：1台の端末を回して順番にプレイ。
- **オンライン対戦**：部屋を作ると5文字の部屋コードが出る。コードか招待リンクを送れば別々の端末から同じ部屋で遊べる。
- **ランキング**：1人で遊んだときの自己ベストが自動で登録され、全員分がランキング表示される。

## 構成

```
public/index.html            ゲーム本体（HTML 1枚）
src/worker.js                Cloudflare Worker（静的ファイル配信 + ランキング API）
migrations/                  D1 のテーブル定義
wrangler.toml                Workers / D1 の設定
```

- サイトは Cloudflare Workers で配信し、ランキングは Cloudflare D1 に保存する。
- ランキング API
  - `GET /api/scores?limit=100&me=<playerId>`：上位と自分の順位
  - `POST /api/scores`（`{ playerId, name, sec }`）：記録を送信。自己ベストのときだけ記録を更新する
- プレイヤーはブラウザごとにランダムな ID で区別する（ログイン不要）。同じ人でも別の端末・ブラウザだと別人扱い。
- 一致桁数はサーバー側でも計算し直す。ただし秒数自体はブラウザから送られるので、やろうと思えば記録は偽装できる（クソゲーなので割り切り）。
- 「経過時間を表示する（ぬるいモード）」の記録はランキングに登録しない。

## デプロイ（初回）

```sh
npm install
npx wrangler login
npx wrangler d1 create pisec      # 表示された database_id を wrangler.toml に貼る
npm run deploy                    # テーブル作成（migrations）+ デプロイ
```

`https://pisec.<あなたのサブドメイン>.workers.dev` で公開される。

GitHub の push で自動デプロイしたい場合は、Cloudflare ダッシュボードの Workers & Pages → 作成 → 「リポジトリをインポート」でこのリポジトリをつなぎ、デプロイコマンドを `npm run deploy` にする。

## ローカルで動かす

```sh
npm install
npm run dev                       # http://localhost:8787
```

## オンライン対戦について

- 通信は [PeerJS](https://peerjs.com/)（WebRTC の P2P）。接続の仲介には PeerJS の無料公開サーバーを使う。
- 計測は各自の端末で行い、記録（秒数）だけを送るので、通信の遅れは記録に影響しない。
- 部屋を作った人（ホスト）がタブを閉じると部屋は解散する。
- 中継（TURN）サーバーは使っていないため、一部のモバイル回線や社内ネットワークでは接続できないことがある。

## メモ

- 計測は `performance.now()`。ブラウザがセキュリティ上の理由で精度を丸めるため、実際に意味がある桁は 0.1ms 〜 1ms 程度（ブラウザ依存）。
- スペース / Enter キーでもボタンを押せる。
