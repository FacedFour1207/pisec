# π秒見積もり

稲刈り遠征中に思いついたクソゲー。

- 必要人数：2人以上推奨、1人でも可
- 遊び方：ボタンを押してスタート → π秒（3.14159…秒）経ったと思ったらもう一度押す。小数点以下何桁までπと一致したかを競う。同じ桁数ならπとの差が小さい方が勝ち。

## 起動

`index.html` をブラウザで開くだけ。サーバー不要（オンライン対戦は PeerJS を CDN から読み込む）。
GitHub Pages で公開すればスマホでもそのまま遊べます。

## オンライン対戦

「オンライン対戦」タブで部屋を作ると5文字の部屋コードが出ます。コードか招待リンクを友達に送れば、別々の端末から同じ部屋で遊べます。

- 計測は各自の端末で行い、記録（秒数）だけを送るので、通信の遅れは記録に影響しません。
- 通信は [PeerJS](https://peerjs.com/)（WebRTC の P2P）を使っています。接続の仲介には PeerJS の無料公開サーバーを使うので、自前のサーバーは不要です。
- 部屋を作った人（ホスト）がタブを閉じると部屋は解散します。
- 中継（TURN）サーバーは使っていないため、一部のモバイル回線や社内ネットワークでは接続できないことがあります。

## メモ

- 計測は `performance.now()`。ブラウザがセキュリティ上の理由で精度を丸めるため、実際に意味がある桁は 0.1ms 〜 1ms 程度（ブラウザ依存）。
- スペース / Enter キーでもボタンを押せます。
- 「経過時間を表示する」をオンにすると経過秒数が見える（ぬるいモード）。
